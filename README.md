# Product Inventory Basic

A simple console application written in C#. This is an educational project to practice the basics of Object-Oriented Programming (OOP), specifically creating classes and using constructors.

## Features
* **Product Class:** Created a base class to describe a product with public fields `Name`, `Price`, and `Stock`.
* **Constructor with parameters:** Implemented a custom constructor `public Product(...)` that allows setting all product data in a single line upon creation.
* **Object Creation:** Instantiated two independent product objects (`product1` — Laptop and `product2` — Iphone) inside the `Program` class.
* **Data Output:** Used string interpolation (`$""`) to format and print the details of each product to the console.

## What I learned in this project
* How to properly pass parameters into a constructor and save them to the object's internal fields (`Name = name;`).
* The difference between a class (a blueprint of a product) and a specific object (a laptop or a phone) created from that blueprint.
* Basic usage of data types like `string` (text) and `int` (whole numbers) when designing a class structure.
